# x402 Field Guide (Sample Purchased File)

This file demonstrates a paid digital download.

## What a buyer receives

- A Markdown document streamed over HTTP after settlement.
- Repeat access when the same wallet signs a fresh SIWX challenge.
- No new payment for the same file while the permanent grant remains recorded.

## Lab rules

1. Only Base Sepolia **test** USDC is used.
2. Keep your test wallet's `.env` private.
3. Losing the first HTTP response must not mean that the buyer loses access to this file.
4. An on-chain payment authorization is NOT an identity session.
5. A Payment-Identifier is NOT, by itself, sufficient to grant access to a paid resource.

This is sample learning material, not a real commercial product.
